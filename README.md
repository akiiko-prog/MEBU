# MEBU

Fork modifié de [Chrysalide](https://chrysalide.app/) / [Papillon](https://github.com/PapillonApp/Papillon),
adapté pour le portail Auriga de l'ESME (my.esme.fr).

L'app comprendra une interface permettant de visualiser l'epdt des eleves respectivement, ainsi qu'une gestion des evenements scolaire, des retards et abscences en cours, et un calculateur de moyenne.

Pour changer les permission de créer/modifier/supprimer des évent il faut ouvrir le fichier utils/permissions/eventPermissions.ts et suivre les indications de ce fichier.
